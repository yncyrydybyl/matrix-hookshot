What is Hookshot?
Integrations

8 Integrations

GitHub, GitLab, JIRA, generic webhooks, RSS/Atom feeds, Figma, OpenProject, ChallengeHound. One deployment, all services.

No Database Required

Connection configuration stored as Matrix room state events. State travels with rooms, survives upgrades, works with federation.

Bidirectional

Receive notifications in Matrix rooms. Send commands back to external services. Map emoji reactions to GitHub actions.

Fine-Grained Permissions

Per-user, per-service, per-domain access control. Different teams get different access levels.

Programmable Webhooks

Accept any HTTP payload with optional JavaScript transformation functions in a sandboxed runtime.

Production Ready

Prometheus metrics, Sentry integration, Redis caching, worker scaling, E2EE support, health probes.
