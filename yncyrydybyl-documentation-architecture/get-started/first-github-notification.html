Your First GitHub Notification ​

Connect a GitHub repository to a Matrix room. When a pull request is opened, a notification appears in the room.

Prerequisites:

  • A running hookshot instance with GitHub configured
  • A GitHub repository you have admin access to (for installing the GitHub App)

Step 1: Install the GitHub App ​

If not already done, install the GitHub App on your repository or organization. The App provides webhook delivery and API access.

See GitHub setup for detailed instructions.

Step 2: Authenticate (optional) ​

For commands that act as you (not required for receiving notifications):

DM the hookshot bot:

!github login

Follow the OAuth link. See GitHub authentication for details.

Check status: !github status

Step 3: Connect a room to a repository ​

In your Matrix room:

!hookshot github repo https://github.com/your-org/your-repo

Hookshot confirms the connection was created. This writes a room state event (uk.half-shot.matrix-hookshot.github.repository).

Alternatively, use the widget UI or provisioning API.

Step 4: Trigger a notification ​

Open a pull request on the connected repository. Within seconds, a message appears in the Matrix room:

🔵 your-username opened a new PR your-org/your-repo#1: "Your PR title"

This is hookshot's inbound event flow in action: GitHub webhook → signature verification → message queue → connection handler → Matrix message.

Step 5: Try a command ​

Create an issue from Matrix:

!gh create "Test issue from Matrix"

Hookshot creates the issue on GitHub and confirms in the room. This is the outbound flow.

See all GitHub bot commands or the full bot commands reference.

Step 6: Try emoji reactions ​

React to the PR notification message with 👍. Hookshot adds a thumbs-up reaction on the GitHub PR.

React with ✅ to approve the PR. See all emoji mappings.

What you learned ​

  • GitHub integration uses a GitHub App for webhooks and API access
  • Connections bind a Matrix room to a GitHub repo via room state events
  • 13 event types are enabled by default, including PRs, issues, and releases
  • Bot commands let you create issues and trigger workflows from Matrix
  • Emoji reactions map to GitHub actions

Customizing ​

  • Enable more events (e.g., push, workflow.run): Update the connection via widget or connection options
  • Filter by labels: Use includingLabels / excludingLabels in connection options
  • Change command prefix: Set commandPrefix in connection options (default: !gh)
